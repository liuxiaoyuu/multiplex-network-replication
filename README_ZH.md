# 信息如何沿着社会关系传播

[English](README.md) · [中文](README_ZH.md)

一个家庭可能向这位邻居借米，去另一家串门，遇到问题时又向第三个人请教。当一条消息进入村庄，哪一种关系更能帮助我们理解它会传到多远？

Chandrasekhar 等（2026）用印度村庄的数据研究这个问题，把每一种关系分别看作一张网络。我复现了论文的一部分分析，并在此基础上追问了一个问题。

[原文（PNAS）](https://doi.org/10.1073/pnas.2534923123) · [预印本](https://arxiv.org/pdf/2412.11957) · [作者数据与代码](https://github.com/v-asu/multiplexing-and-diffusion-replication-package)

![同一个村庄的不同关系网络](results/network_multiplex_village2.png)

*同一个村庄的 142 个家庭，用不同的关系画出来。橙色点是最先获得信息的家庭。*

## 主要发现

**复现结果一致。** 我从原始数据重建了各村的关系网络，复现了论文 Table S2 背后的九组模型，结果与原文数值一致；和原文一样，建议关系对结果的解释最好。

**加入更多关系类型，没有稳定地改善预测。** 我检验了同时使用五类基本关系，是否比只用建议关系更能预测一个新村庄的回应。在 68 个村庄的不同分组方式下，都没有看到稳定的改善。在这样的样本量下，结论会受到使用哪些村庄的影响。

## 尚待回答的问题

- 网络信息对预测的帮助整体很有限：建议关系模型只比直接用村庄平均值去猜略准一点。
- 如果只保留“实际记录的最先获知家庭数”与“计划分配数”一致的村庄，结论会发生变化，数据记录方式值得进一步核查。
- 我没有复现论文的理论推导、模拟和作者自己的模型选择流程，所以这是一个范围较窄的检查，不是对论文主要结论的检验。

以下是本项目的扩展分析，没有对应的原文数值。每次留出一个村庄，用其余村庄建立模型，再预测该村的登记电话数。

| 模型 | 逐村留出的 RMSE | MAE |
|---|---:|---:|
| 用训练样本平均值预测 | 11.611 | 8.242 |
| 建议关系 + 控制变量 | 11.376 | 8.316 |
| 五类关系，普通线性回归 | 11.659 | 8.231 |
| 五类关系，岭回归 | 11.227 | 8.032 |

两种误差均以电话数计，越小越好。RMSE 对较大的错误更敏感，MAE 是预测与实际值之间绝对差距的平均数。建议模型的 RMSE 略低于平均值基准，但 MAE 略高，因此不能说它在所有指标上都更准。

岭回归的 RMSE 比建议模型低约 1.3%；但在十次五折比较中，两个五类关系模型各自都只有两次优于建议模型。标准化和调参只使用训练数据。这些比较使用同一批村庄的不同分组，不是对新采集村庄的独立验证，也不同于作者 Table 1 的模型选择流程。

## 运行方法

需要 R 4.6.0 和 Python 3.10+，R 包版本记录在 `renv.lock` 中。

```sh
Rscript setup.R
python3 code/fetch_inputs.py
python3 code/fetch_network.py
python3 run.py
```

原始文件下载至 `private_inputs/`，结果写入 `results/`。作者数据和脚本由原始来源提供，使用条件见[来源说明](docs/SOURCE_AUDIT.md)。
